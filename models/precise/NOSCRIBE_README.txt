Das Modell "precise" ist Whisper large-v3-turbo (float16, ca. 1,6 GB).

Es liegt nicht im Repository. Zum Herunterladen aus dem Projektverzeichnis:

    python scripts/fetch_models.py --only precise

Traudi lädt das Modell auch beim ersten Start automatisch in das
Nutzerverzeichnis, falls hier keines liegt.

Quelle: https://huggingface.co/dropbox-dash/faster-whisper-large-v3-turbo
